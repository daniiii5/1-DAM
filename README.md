# 💻 1º DAM — Repositorio de prácticas y proyectos

Este repositorio contiene todos los **ejercicios, prácticas y proyectos** realizados durante el **primer curso del Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.  

Organizo aquí todo mi trabajo de clase, dividido por módulos y lenguajes, utilizando **Git y GitHub** como herramienta de control de versiones y seguimiento del progreso.

---

## 🎯 Objetivo del repositorio

- Centralizar todas las prácticas realizadas en el curso.  
- Practicar el uso profesional de **Git** y **GitHub**.  
- Llevar un seguimiento del aprendizaje a lo largo del curso.  
- Servir como **portafolio académico** y de referencia.

---

## 🏫 Sobre el ciclo DAM

El **Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)** forma a desarrolladores capaces de crear, implantar y mantener aplicaciones informáticas multiplataforma.  
Durante el primer curso se estudian y practican los fundamentos de la programación, bases de datos, sistemas operativos y desarrollo web.

### 🧩 Módulos principales del primer curso:

- **Programación** (Java, C++)  
- **Lenguajes de Marcas y Sistemas de Gestión de Información** (HTML, XML, CSS, SQL)  
- **Bases de Datos** (MySQL)  
- **Entornos de Desarrollo** (Eclipse, IntelliJ, Visual Studio)  
- **Sistemas Informáticos** (Windows 11, Windows Server, Virtualización)

## 🧠 Contenido destacado

### 🟦 Java
Ejercicios desde la introducción hasta estructuras de control, bucles, condicionales y strings. Incluye proyectos prácticos como **Ahorcado**.

### 🟪 C++
Primeros pasos con la programación estructurada y ejercicios básicos.

### 🟧 HTML
Ejercicios y entregas de **Lenguajes de marcas**, con páginas web, formularios y estilos.

### 🟨 MySQL
Prácticas de **consultas, creación de tablas y bases de datos relacionales**.

### 🟩 OS (Sistemas Operativos)
Carpetas con máquinas virtuales de **Windows 11** (cliente) y **Windows Server 2019** (servidor) con sus snapshots y discos virtuales.
